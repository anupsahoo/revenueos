One source of truth

Nothing on the screen is stored. Every number is derived from an append-only log.

Event log brief.arrived
draft.generated
draft.accepted
draft.rejected
sla.breached
trigger.fired
age → business days since arrival
status → green / amber / red
reuse rate → accepted ÷ decided
boosts → ±8 per decision
triggers → who was escalated

Every number on screen has an ⓘ that shows the query behind it. If it cannot, it does not go on the screen.

7

It learns from the decision, not from a rating

No feedback form. The button is the signal.

Accept → + 8 to every template that draft used
Reject → − 8 to every template that draft used
Boosts are derived from the event log — the server reads them itself and ignores anything the browser sends.

Refresh the page and the decision is still there. It was never browser state.

8

What is real, and what breaks first

Said before anyone has to ask.

Real

  • Event log, derive functions, tests
  • Retrieval scoring and its reasons
  • The agent, the tools, the refusals
  • SLA breach detection and escalation

Not real yet

  • Data is synthetic and labelled on screen
  • Store is in memory — a cold start loses it
  • No auth, one tenant, no workers
  • Breaks first at 10×: the store (#53)

46 open issues, 18 closed. Nothing is closed unless code exists behind it.

9

The one thing I would never hand to the agent

The accept.

Pressing Accept is not a document being finished. It is a promise to a customer about what we will prove, in how many weeks, under their regulator.

The person who makes that promise has to be the person who will be in the room when it slips.
